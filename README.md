# AI Brand Storytelling | Strategy, Voice, and Narrative System

An English Codex Skill that combines guided brand discovery, strategic concept development, and style-led copywriting in one structured workshop.

It does not begin by producing a handful of decorative lines. It finds what the brand deserves to be remembered for, then builds a narrative system that can guide naming, slogans, brand stories, and future content.

## Method

```text
Brand discovery → Core metaphor → Style hierarchy → Narrative system → Content extensions
```

The Skill clarifies the brand or project, concrete strengths, audience, communication challenge, and desired voice. The user can select two to four of 18 defined styles and appoint one dominant style; supporting styles add controlled depth without muddying the voice.

## Deliverables

1. Three core concept metaphors and a recommended direction
2. An official interpretation of the brand name
3. A Slogan, philosophy Tagline, and social Hashtag
4. A 250–350 word brand story
5. Narrative pillars plus recommended and prohibited vocabulary

## Six creative principles

- Begin with an emotional anchor
- Let one extensible metaphor govern the system
- Give emotional language a rational strategic skeleton
- Prefer precision to decorative excess
- Express abstract ideas without relying on quotation marks
- Blend one dominant and up to three supporting styles hierarchically

Before delivery, the Skill scans for over-explained contrast formulas, abstract emphasis in quotation marks, unsupported claims, and muddled style blending. Only the clean rewritten version is shown.

## Good use cases

- Establishing a new brand narrative and tone of voice
- Luxury, property, cultural, and public-brand campaigns
- Developing naming concepts and campaign lines
- Turning scattered product strengths into one extensible creative platform
- Building a consistent source narrative for social, email, and web content

## Installation

```bash
git clone https://github.com/cityminutes/ai-brand-storytelling-en.git ~/.codex/skills/ai-brand-storytelling-en
```

Then invoke it in Codex:

```text
Use $ai-brand-storytelling-en to interview me and build a complete core narrative system for this brand.
```

If you already have a substantial brief, paste it directly. The Skill will summarize known information and ask only for material strategic gaps.
